# Screenshot Assets

This directory contains screenshots for the rdreh GitHub Pages landing site.

## Specifications
- **Format:** PNG or WebP
- **Dimensions:** 1600 × 1000 pixels (16:10 aspect ratio)

## Present files
- `hero.png`: Agents multi-pane session (resized 1600x1000)
- `cockpit.png`: Editor / terminal layout (resized 1600x1000)
- `tokens.png`: Telemetry dashboard (resized 1600x1000)
